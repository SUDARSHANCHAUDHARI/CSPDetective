# CSP Detective

Browser security and iframe diagnostics platform

## What it is

AI-powered tool that explains why websites fail inside iframes, kiosk browsers, signage players, and embedded dashboards.

## Features

- HTTP header inspection
- CSP analysis
- X-Frame-Options detection
- Iframe compatibility testing
- Browser compatibility matrix
- Playwright rendering tests
- Console error capture
- AI explanations and fixes
- Security scoring

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Playwright
- OpenAI / Claude
- PostgreSQL
- Redis
